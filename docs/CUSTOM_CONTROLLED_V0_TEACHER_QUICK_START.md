# Custom Controlled V0 Teacher Quick Start

This guide is for the first supervised Custom Controlled V0 teacher test.

Use it slowly and carefully. The system can help prepare evidence and suggest draft marks, but the teacher remains responsible for the final decision.

## 1. What this pilot does

This pilot helps with a small, controlled marking workflow.

It can:

- help prepare evidence for one question;
- keep the question, model answer, rubric, student answer text, and answer evidence together;
- create AI draft grade suggestions when the evidence is ready;
- show the teacher the draft score, feedback, rubric breakdown, and evidence;
- let the teacher approve a final grade only after review;
- export approved final grades only.

Important: the AI result is only a draft suggestion. It is not the final mark until the teacher reviews and approves it.

## 2. What this pilot does not do

This pilot does not:

- automatically find student answers;
- perform OCR;
- read handwriting automatically;
- grade many scripts in a batch;
- create automatic final grades;
- replace teacher judgement;
- run fully automated grading.

If something looks automatic when it should not be, stop and ask the observer/founder before continuing.

## 3. Materials the teacher needs

Before starting, prepare:

- the question text;
- the model answer or solution;
- the rubric or mark breakdown;
- the student scripts for the test;
- the teacher-confirmed student answer text for each answer evidence region.

For the first supervised test, use synthetic/demo scripts unless real data has been explicitly approved.

## 4. Step-by-step guide

### Step 1: Create or open the assessment

Open the assessment for the supervised test, or create a new one if instructed.

Check that it is the correct test assessment before adding student work.

### Step 2: Add the question

Add the question that will be marked.

For the first test, use only one question.

### Step 3: Add the model answer

Add the model answer or solution text.

Do not continue to grading if the model answer is missing or unclear.

### Step 4: Add the rubric

Add the rubric or mark breakdown.

The rubric should show how the marks are awarded. For example, a 10-mark question may have two criteria worth 6 marks and 4 marks.

Do not continue to grading if the rubric is missing or unclear.

### Step 5: Upload or attach the student script

Upload or attach the student script for the assessment.

For the first test, use only the approved synthetic/demo scripts.

### Step 6: Select or create the answer evidence region

Select the part of the script that contains the student's answer for the question.

This evidence region should clearly match the answer that will be graded.

### Step 7: Enter teacher-confirmed manual answer text

Type or paste the student's answer text into the manual answer text field.

This text must be checked by the teacher. It should match the selected evidence region.

Do not grade if this text is missing.

### Step 8: Confirm evidence readiness

Check the evidence preview before grading.

The preview should show:

- the manual student answer text;
- the model answer;
- the rubric;
- the selected answer evidence region;
- no blockers.

Only continue if the packet is marked ready for grading.

### Step 9: Queue the ready packet

Add the ready packet to the queue.

The queue is only a preparation list. It should not grade automatically.

### Step 10: Run one real draft grade

Run one real AI draft grade only when the observer/founder confirms it is allowed.

For the first teacher test, run one packet at a time. Do not run batch grading.

### Step 11: Review score, feedback, rubric breakdown, and evidence

Review the draft carefully.

Check:

- the score;
- the feedback;
- the rubric breakdown;
- the student answer evidence;
- the model answer;
- whether the suggested marks match the rubric.

If the score or feedback looks wrong, stop. Do not approve blindly.

### Step 12: Approve only after review

Approve only if the teacher agrees with the draft result after review.

If the result is wrong or uncertain, do not approve it. Ask the observer/founder what to do next.

### Step 13: Export approved final grades

Export only after the needed final grades have been approved.

The export should include approved final grades only. Draft suggestions should not appear as final grades.

## 5. Safety rules for the teacher

- Do not use private or high-stakes student data in the first pilot unless it has been explicitly approved.
- Do not grade if the manual answer text is missing.
- Do not grade if the model answer is missing.
- Do not grade if the rubric is missing.
- Do not approve blindly.
- Stop if the score or feedback looks wrong.
- Stop if the evidence preview does not match the student answer.
- Stop if anything appears to run automatically without teacher action.
- The teacher remains the final authority.

## 6. Expected first test shape

The first supervised teacher test should be small:

- 1 teacher;
- 1 assessment;
- 1 question;
- 2 student scripts;
- 2 manual answer texts;
- 2 AI draft suggestions;
- 2 teacher approvals only if correct;
- 1 approved-only export.

Do not expand beyond this shape unless the founder explicitly approves it.

## 7. Troubleshooting

### Missing model answer

Stop before grading.

Add or correct the model answer, then check the evidence preview again.

### Missing rubric

Stop before grading.

Add or correct the rubric, then check the evidence preview again.

### Missing manual answer text

Stop before grading.

Enter the teacher-confirmed student answer text. Make sure it matches the selected answer region.

### Not ready for grading

Do not run an AI draft grade.

Check the readiness message and fix the missing item. Common causes are missing manual answer text, missing model answer, missing rubric, or missing answer evidence region.

### Codex/provider unavailable

Stop the grading attempt.

Do not retry unless the founder/observer explicitly approves a retry. Record what happened in the pilot report.

### Score looks wrong

Do not approve.

Review the student answer, model answer, rubric, and feedback. If the score still looks wrong, stop and report the issue.

### Export has missing rows

Check whether the missing rows were approved as final grades.

The export should include approved final grades only. Draft suggestions should be excluded.

## 8. One-page teacher checklist

### Before grading

- [ ] I am using the approved test assessment.
- [ ] The data is synthetic/demo, or explicitly approved for this pilot.
- [ ] The question text is present.
- [ ] The model answer or solution is present.
- [ ] The rubric or mark breakdown is present.
- [ ] The student script is attached.
- [ ] The answer evidence region is selected.
- [ ] The manual student answer text is entered and checked.
- [ ] The evidence preview shows manual answer text, model answer, rubric, and answer evidence.
- [ ] The packet is ready for grading.

### During review

- [ ] I checked the suggested score.
- [ ] I checked the feedback.
- [ ] I checked the rubric breakdown.
- [ ] I checked the linked evidence.
- [ ] I checked that the draft suggestion matches the rubric.
- [ ] I understand this is not final until I approve it.

### Before approval and export

- [ ] I agree with the final score.
- [ ] I agree with the feedback or understand its limitations.
- [ ] I am approving only after review.
- [ ] I know the export should include approved final grades only.
- [ ] I checked that drafts are not being treated as final grades.

### When to stop

Stop immediately if:

- private or unapproved student data appears;
- manual answer text is missing;
- the model answer is missing;
- the rubric is missing;
- the evidence region is wrong;
- the packet is not ready;
- the score or feedback looks wrong;
- the AI/provider is unavailable;
- batch grading appears;
- a final grade appears before teacher approval;
- the export includes unapproved draft suggestions.
